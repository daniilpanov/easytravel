# Contributing

## Branches

- Create a new branch for each task or task group.
- Allowed prefixes: `feature/`, `refactor/`, `improve/`, `fix/`.

## Commits

- Every commit must leave the code in a working state.
- Use `rebase` or `amend` when history needs cleanup.
- The commit title must describe the essence of the change, not the action performed.
  - Good: `feat: implement agent validation feature`
  - Bad: `feat: add agent_validation.py`
- Keep all information in the title. Avoid the commit body.
- If details are unavoidable, use a short bullet list without filler.

## Pull requests

- Do not merge branches yourself. Integration happens only through pull requests.
